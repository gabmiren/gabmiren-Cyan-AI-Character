# Cyan AI Character

Locked assets for realistic AI videos of Cyan. Board: https://gabmiren.github.io/gabmiren-cyan-ai-character/

## Folders

- `cast/` character sheets (one per person) and detail close-ups
- `sets/` location plates, one folder per location, extra angles of the same room
- `props/` objects the script uses
- `voice/` Cyan's voice sample and pronunciation clips
- `scripts/` scripts and shooting plans
- `keyframes/` approved keyframes per video
- `renders/` final exports

## Rules

- Files named `*-master` are the approved versions. Always build new images from a master, never from a drifted output.
- Send models the raw GitHub link, not an attachment.
- Add every newly locked asset to `assets.json` so it shows on the board, in send order.
